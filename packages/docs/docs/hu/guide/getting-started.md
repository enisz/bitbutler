# Kezdő lépések

A BitButler egy asztali alkalmazás - telepítsd Windowsra vagy Linuxra, majd irányítsd egy már futó qBittorrent-nox szerverre. Maga nem futtat torrenteket; lásd [Miért a BitButler](./why-bitbutler), hogy a két rész hogyan illeszkedik egymáshoz.

## Telepítés

Töltsd le a platformodnak megfelelő buildet a projekt [GitHub Releases](https://github.com/enisz/bitbutler/releases) oldaláról.

### Windows

Két lehetőség áll rendelkezésre: egy végigvezetett **telepítő** (választhatsz telepítési helyet, és Start menü / Asztal parancsikonokat hoz létre), vagy egy **hordozható (portable)** build, amelyet telepítés nélkül, közvetlenül futtathatsz. Egy sima `.zip` fájl is elérhető a hordozható buildből, ha inkább magad csomagolnád ki.

### Linux

Elérhető **AppImage**-ként (közvetlenül futtatható, telepítés nélkül), illetve **.deb**, **.rpm** vagy **snap** csomagként a disztribúciód csomagkezelőjéhez, valamint egy sima `.tar.gz` archívumként.

## Első indítás

A BitButler első indításakor még nincs beállítva szerver, ezért egyből a bejelentkezési képernyőt nyitja meg a torrentlista helyett. Innen folytasd az [Első lépések](./first-steps) oldallal az első szerverkapcsolat hozzáadásához.
