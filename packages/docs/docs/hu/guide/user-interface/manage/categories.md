# Kategóriák

Nyisd meg a **Kezelés > Kategóriák** menüpontot. Minden kategóriának van neve és egy opcionális mentési útvonala - egy kategória torrenthez rendelése automatikusan áthelyezheti azt az adott útvonalra, a qBittorrent [Mentéskezelés](../settings/qbittorrent-settings#menteskezeles) beállításaitól függően. Használd a szűrőmezőt a meglévő kategóriák kereséséhez, a ceruzaikont egy kategória mentési útvonalának szerkesztéséhez, a kukaikont pedig egy kategória törléséhez; a törlés megerősítés előtt megmutatja, hány torrent használja jelenleg azt a kategóriát.
