# Címkék

Nyisd meg a **Kezelés > Címkék** menüpontot. A kategóriáktól eltérően egy torrenthez több címke is tartozhat. Adj hozzá többet egyszerre egy vesszővel elválasztott lista megadásával a névmezőben. Használd a szűrőmezőt a kereséshez, a kukaikont pedig egy címke törléséhez - a megerősítés megmutatja, hány torrent használja jelenleg azt.
