# Categories

Open **Manage > Categories**. Each category has a name and an optional save path - assigning a category to a torrent can automatically relocate it to that path, depending on your qBittorrent [Save Management](../settings/qbittorrent-settings#save-management) settings. Use the filter box to search existing categories, the pencil icon to edit a category's save path, and the trash icon to delete one; deleting shows how many torrents currently use that category before you confirm.
